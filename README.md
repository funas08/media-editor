# 画像エディタ

ブラウザで動く、シンプルな画像・動画編集 Web アプリです。
複数のスクリーンショットを WQHD や 4K のキャンバスに並べて1枚にまとめる作業と、トリミング・リサイズ・回転・色調補正などの基本的な編集ができます。
動画モードでは、動画をつないで MP4 に書き出せます（開発中）。

- **画像・動画は外部に送信しません。** バックエンドがない静的サイトで、読み込み・編集・書き出しはすべてブラウザの中で行います。
- **非破壊編集。** 元画像はそのまま保持し、トリミングや色調補正はパラメータとして持ちます。後からいつでも解除・調整できます。
- **外部ライブラリは最小限。** Vite + TypeScript と Canvas 2D API で作っています。動画の読み書きにだけ [Mediabunny](https://mediabunny.dev/) を使っています。

## 主な機能

### 並べる（G）
複数の画像をグリッド状に並べて1枚にします。

- 枚数とキャンバスの縦横比から行・列を自動提案（例：FHD 4枚 → WQHD に 2×2、1セル 1280×720）
- 間隔・余白、「収める（余白あり）」／「埋める（はみ出しを中央で切り抜き）」
- 並び順（レイヤー順／ファイル名順）、選択中の画像だけを並べることも可能
- 確定前に配置結果をプレビュー表示

### 編集ツール
| ツール | キー | 内容 |
|---|---|---|
| 選択・移動 | V | クリック・範囲選択、ドラッグ移動、矢印キー、スナップとガイド線、整列・等間隔分布 |
| トリミング | C | 対象はキャンバス全体か選択中の画像。切り抜きの形（四角形・角丸・楕円）、比率（自由／元比率／1:1／4:3／3:2／16:9／9:16／数値指定）、「正方形」「正円」プリセット、Shift で比率固定・Alt で中心固定、三分割線、数値入力。キャンバスは外側まで広げることもできる |
| サイズ変更 | R | 8方向ハンドル、px / % 入力、等倍、キャンバスに収める／埋める |
| 回転・反転 | T | 回転ハンドル（Shift で 15° 刻み）、90° 回転、左右・上下反転 |
| 色調補正 | A | 明るさ・コントラスト・彩度・色相・グレースケール・ぼかし |
| 並べる | G | 上記 |
| キャンバス | K | サイズのプリセット（FHD / WQHD / 4K と各縦向き、任意サイズ）、背景色、透明、選択した画像に合わせる、キャンバスの形の解除 |
| 手のひら | H | ドラッグで表示位置を移動 |

### 共通
- 新規作成（起動時にも表示）：「画像を開く」（キャンバスが画像のサイズになる）／「白紙から作成」（サイズと背景を選ぶ）／「プロジェクトを開く」
- 画像の追加：今のキャンバスに、ファイル選択・ドラッグ&ドロップ・貼り付け（Ctrl+V）で追加。複数枚まとめて
- 保存していない変更があるときに新規作成・開くをすると確認を表示
- ズーム（ホイール・カーソル位置基準）、Space+ドラッグでパン、高 DPI 対応
- 元に戻す／やり直し（ドラッグ1回分は1回で戻る）
- レイヤー一覧：表示/非表示、ロック、前面・背面、複製、削除、名前の変更
- 書き出し：PNG / JPEG / WebP、品質、倍率（1x / 1.5x / 2x。WQHD×1.5 = 4K）
- プロジェクトの保存・読み込み：状態と元画像を1つの `.json` にまとめて保存

### 動画モード（開発中）
上部バーで「画像 / 動画」を切り替えます。動画モードでは画面下にタイムラインが出ます。キャンバス・ツール・左パネルは画像モードと共通です。

- トラック（上ほど手前）：オーバーレイ（複数・「＋トラック」で追加・表示/非表示・ロック）/ メイン / 元音声 / 音楽
  - メイン：動画と画像（静止画、既定 5 秒）を隙間なく順に並べる。全クリップがつながった1本として書き出される
  - オーバーレイ：画像・動画（ワイプ）を好きな時刻に重ねる
- 素材パネル（左下の「素材」タブ）：読み込んだ動画・画像・音楽の一覧（動画は元のビットレートも表示。項目にカーソルを置くとコーデック・色空間）。同じ素材を何度でも置ける
- ドラッグ&ドロップ：素材パネルやパソコンのファイルを、タイムライン（メイン・オーバーレイ・新しいトラック）やキャンバスに置く。
  メインでは境目に吸着し、クリップの途中なら分割して挿入。重なるオーバーレイは別のトラックへ
- クリップのドラッグで時刻の移動・並べ替え・トラック間の移動、Alt+ドラッグで複製。境目・再生位置・先頭に吸着
- 編集：クリップの端のドラッグでトリム、S で分割、Delete で削除（メインは後ろを詰める）、I / O で範囲を指定してカット
- 重ね合わせ：位置のプリセット（四隅・中央＋余白）、不透明度、フェードイン/アウト、ワイプの音量（既定はミュート）
- 解像度・縦横比・フレームレートの違う動画を混ぜて書き出せる。メインのクリップはキャンバスに「収める」が既定
- 動画クリップも画像と同じツールで位置・サイズ・回転・トリミング（丸形）・色調補正ができる
- 再生・停止（Space）、1コマ移動（← →、Shift で1秒）、タイムラインのクリック・ドラッグで再生位置の移動、Ctrl+ホイールでズーム
- 元の動画の音声も一緒に再生
- 書き出し：MP4（映像 H.264 / H.265 / AV1、音声 AAC）、タイムライン全体 / I〜O の範囲、倍率（1x / 1.5x / 2x）、30 / 60fps、画質。保存先のファイルに少しずつ書き込み、進捗を表示。
  - 画質：「元の動画に合わせる」（既定）/ 最高画質（品質固定）/ 高画質 / 標準 / 小さいファイル / ビットレートを指定（Mbps）。ビットレートと予想ファイルサイズを表示
    - 「元の動画に合わせる」：メインの元動画のビットレートを、コーデックの違い（H.265・AV1 の元動画は H.264 換算で 1.6〜2 倍）で換算し、再エンコードによる劣化を補うため 1.3 倍にする
    - 「最高画質（品質固定）」：ビットレートではなく画質を一定に保つ（QP 18 相当）。使えない環境では高いビットレートで書き出す
  - 映像のコーデック：H.264（High プロファイル）/ H.265 / AV1（この環境で使えるもののみ）
  - エンコーダー：自動（ハードウェア優先）/ ハードウェア / ソフトウェアを選べる。可変ビットレート・画質優先、キーフレーム間隔は元の動画に合わせる（1〜5 秒）
  - 元動画と同じ色空間（BT.709 など）の情報を付けて書き出す
  - 元動画と同じ大きさで変形していないクリップは、拡大・縮小せずそのままの画素で描く。拡大・縮小される場合はダイアログで注意を表示
  AAC が使えない環境では「音声なしで書き出す」を選べる
- 対応ブラウザ：WebCodecs が使える Chrome / Edge の最新版

ショートカットの一覧は、アプリで `?` キーを押すと表示されます。

## 動作環境

- ブラウザ：Chrome / Edge の最新版
- 開発：Node.js 20.19 以上（または 22.12 以上）

## 使い方（開発環境で起動）

```bash
npm install
npm run dev
```

表示された URL（通常は http://localhost:5173 ）をブラウザで開きます。

### ビルド

```bash
npm run build     # 型チェック（tsc）と本番ビルド。dist/ に出力
npm run preview   # ビルド結果をローカルで確認
```

`dist/` は静的ファイルだけなので、任意の静的ホスティングにそのまま置けます。

### テスト

```bash
npm test          # Node.js で計算ロジックと動画書き出しの流れのテストを実行（tests/**/*.test.ts）
npm run inspect-video <ファイル>...   # 動画ファイルの長さ・解像度・トラック数・ビットレート・プロファイル・色空間を表示（複数並べて比較できる）
```

Node.js には WebCodecs がないため、テストでは映像・音声のエンコードだけを仮の処理に置き換えて、
MP4 の構造（長さ・解像度・トラック数・フレーム数）を確認しています。実際の H.264 / AAC のエンコードはブラウザで行われます。

### 例：スクリーンショット4枚を WQHD 1枚にまとめる

1. 起動画面（または「新規作成」）で「白紙から作成」→ WQHD を選んで作成し、画像4枚をウィンドウにドラッグ&ドロップする
2. `G` で「並べる」に切り替え、2×2・1セル 1280×720 になっていることを確認して「配置」（または Enter）
3. 「書き出し」で形式と倍率を選んで保存（1.5x にすると 3840×2160 の 4K になる）

### 例：丸いアイコン画像を作る

1. 「画像を開く」で画像を開く
2. `C`（トリミング。対象は「キャンバス」）で「正円」を押し、枠をドラッグして位置と大きさを調整し、Enter で確定
3. 「書き出し」で PNG（または WebP）を選んで保存。円の外側は透明になる（JPEG では背景色）

## プロジェクトの構成

```
src/
  core/      状態の型（DocState）、Editor（状態の一元管理と履歴）、AssetStore（元画像）、幾何計算
  render/    Canvas 2D による描画。アイテムの種類ごとのレンダラーを登録制で管理（描画は時刻を受け取る）
  media/     動画の読み込み・デコード・再生・書き出し（Mediabunny・WebCodecs・Web Audio）
  tools/     Tool インターフェースと各ツール（キャンバス操作と設定欄の UI をセットで持つ）
  features/  並べる・スナップ・整列・トリミング・書き出しなどのロジック（UI に依存しない）
  io/        ファイル入出力、プロジェクトの保存形式（ProjectStorage）
  ui/        上部バー・左パネル・レイヤー一覧・ステータスバー・ダイアログ
tests/       Node.js で実行するテスト
scripts/     テスト実行などの補助スクリプト
docs/        開発用のドキュメント
```

設計の方針：

- 状態の変更はすべて `Editor` を通し、履歴に残す
- 新しいツールは `Tool` を実装して `src/tools/index.ts` に1行追加するだけで、左パネルのボタンと設定欄が増える
- アイテムの描画は種類ごとに `registerItemRenderer` で登録する（将来テキストや図形を追加できる）
- 描画処理は `render/` に閉じ込め、将来 WebGL / WebGPU に差し替えられるようにしている
